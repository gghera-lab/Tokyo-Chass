# Тихий час

Пиксельная антиутопия 18+ в формате Telegram Mini App. Депутат Пушнин, карточка № 212, голосует за закон, после которого законы больше не нужны.

- Играть: https://gghera-lab.github.io/Tokyo-Chass/
- Длительность: 20–30 минут
- Страна, закон и персонажи вымышлены. Исторические параллели с источниками — в архиве игры.

## Запуск в Telegram

1. @BotFather → `/newbot` — создать бота.
2. Bot Settings → Configure Mini App (или Menu Button) — указать ссылку выше.
3. Открыть: `https://t.me/<имя_бота>?startapp`.

Весь проект — один файл `index.html` без сборки.

## Кабинет

Симулятор власти 18+: министр, депутат или президент Мурландии, 40 недель, шесть шкал страны и скрытая коррупция.

- Играть: https://gghera-lab.github.io/Tokyo-Chass/kabinet/
